# Contributing

Thank you for helping improve this project.

## What You Can Contribute

- Fix technical inaccuracies.
- Improve explanations.
- Add diagrams.
- Add practical labs.
- Add MCQs with explanations.
- Improve accessibility and Markdown formatting.
- Add examples for Windows/Linux/macOS where appropriate.

## Contribution Rules

1. Keep explanations beginner-friendly.
2. Prefer technically precise language.
3. Avoid unsupported claims.
4. Keep each topic focused.
5. Every new topic should include an MCQ section and answer key.
6. Do not include dangerous electrical procedures.
7. Use clear filenames and headings.

## Pull Request Checklist

- [ ] Content is technically reviewed.
- [ ] Markdown renders correctly.
- [ ] MCQs have correct answers.
- [ ] Practical task is safe.
- [ ] No unnecessary duplication.
- [ ] Links work.
