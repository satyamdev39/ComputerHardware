# 05 — Storage: HDD, SSD & NVMe

## 1. HDD

Hard Disk Drives store data magnetically on rotating platters.

Advantages:
- High capacities can be cost-effective.
- Suitable for bulk storage.

Limitations:
- Mechanical parts.
- Higher latency than SSDs.

## 2. SATA SSD

Uses flash memory with a SATA interface. It has no moving platters and is generally much faster than an HDD.

## 3. NVMe SSD

NVMe is a storage protocol designed for non-volatile memory and commonly operates over PCIe.
