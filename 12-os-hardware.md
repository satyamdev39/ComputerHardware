# 12 — Operating System ↔ Hardware

## 1. Kernel

The kernel is the core part of an operating system that manages hardware resources and provides services to software.

## 2. Drivers

Device drivers allow the operating system to communicate with particular hardware devices.

## 3. Interrupts

Hardware can signal the processor that an event requires attention. Modern systems use sophisticated interrupt architectures.

## 4. DMA

Direct Memory Access allows suitable hardware devices to transfer data to/from memory with reduced direct CPU involvement for every transfer.

## 5. Device Enumeration

During startup and runtime, the OS discovers devices and associates resources/drivers with them.
