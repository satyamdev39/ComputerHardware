## 🎯 Goal

This repository is designed for anyone who wants to understand how computers are built, how their components communicate, how operating systems interact with hardware, and how to diagnose common hardware problems.

You do **not** need previous hardware knowledge.

## 🧠 How to Study

For every topic:

1. Read the concept.
2. Draw the architecture/flow yourself.
3. Learn the important terminology.
4. Take the MCQ quiz.
5. Perform the suggested practical task.
6. Write your own notes before moving forward.

## 🛠️ Practical Labs

The repository is not only theory. Suggested labs include:

- Identify components inside a desktop PC.
- Enter BIOS/UEFI and inspect hardware information.
- Identify RAM type and installed capacity.
- Compare SATA SSD vs NVMe SSD.
- Monitor CPU/GPU temperatures.
- Inspect storage health.
- Assemble a PC virtually or physically.
- Diagnose boot/no-display symptoms.
- Plan a balanced upgrade.

> ⚠️ Safety: Never open a PSU enclosure. Disconnect power before installing/removing internal components, follow manufacturer instructions, and use appropriate ESD precautions.
