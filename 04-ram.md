# 04 — RAM & Memory

## 1. RAM

Random Access Memory provides relatively fast temporary storage for actively used programs and data.

RAM is normally volatile: its contents are lost when power is removed.

## 2. DRAM

Most system RAM is based on DRAM technology. DRAM cells require periodic refreshing.

## 3. DDR

DDR generations include DDR3, DDR4 and DDR5. They are not interchangeable simply because they look similar.

## 4. Capacity vs Speed vs Latency

- **Capacity:** how much data can be held.
- **Data rate:** how quickly memory transfers data.
- **Latency:** delay associated with accessing data.

Real performance depends on the workload and the complete memory configuration.

## 5. Dual Channel

Using compatible modules in the correct motherboard slots can enable multi-channel memory operation and increase memory bandwidth.
