# 02 — Motherboard & System Architecture

## 1. Motherboard

The motherboard is the main circuit board that provides physical and electrical connections between major components.

## 2. Important Areas

### CPU Socket
Provides the mechanical/electrical interface for the processor.

### DIMM Slots
Slots used for desktop memory modules.

### PCIe Slots
High-speed expansion interfaces commonly used by GPUs and expansion cards.

### M.2
A compact connector used by several devices, commonly NVMe SSDs.

### SATA
Interface commonly used for SATA storage devices.

### VRM
Voltage Regulator Module circuitry converts and regulates power for components such as the CPU.

### Chipset

Modern platform architectures divide system responsibilities between the CPU and platform controller/chipset rather than putting everything into one traditional northbridge/southbridge structure.

## 3. Form Factors

Common motherboard form factors include:

- ATX
- Micro-ATX
- Mini-ITX

Form factor affects physical dimensions, expansion capability and case compatibility.
