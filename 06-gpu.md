# 06 — GPU & Graphics

## 1. GPU

A Graphics Processing Unit is specialized for highly parallel workloads, especially graphics and many compute workloads.

## 2. Integrated vs Discrete

**Integrated GPU:** generally shares system resources or is integrated into the processor/platform.

**Discrete GPU:** a separate graphics processor, typically with dedicated VRAM.

## 3. VRAM

Video memory stores graphics data such as textures, frame buffers and other working data.

## 4. Bottlenecks

A workload may be limited by:

- CPU
- GPU
- RAM
- VRAM
- Storage
- Software/driver overhead

The bottleneck depends on the workload.
