# 13 — Hardware Troubleshooting

## 1. The Golden Rule

**Do not randomly replace components. Diagnose systematically.**

## 2. Troubleshooting Method

```text
Symptom
  ↓
Reproduce
  ↓
Gather evidence
  ↓
Check simple causes
  ↓
Isolate variables
  ↓
Test
  ↓
Repair
  ↓
Verify
  ↓
Document
```

## 3. No Power

Check:

- Wall power
- Power cable
- PSU switch
- Motherboard power connections
- Case power switch/header
- PSU/system condition

## 4. No Display

Check:

- Monitor input
- Display cable
- GPU seating
- Correct video output
- RAM seating/configuration
- POST indicators
- Known-good components where appropriate

## 5. Overheating

Check:

- Fan operation
- Cooler mounting
- Thermal interface
- Dust/airflow
- Ambient temperature
- CPU/GPU workload

## 6. Random Shutdown

Potential areas:

- Power delivery
- Thermal protection
- Hardware instability
- Driver/OS issues
- Faulty components

Use logs and controlled tests rather than guessing.
