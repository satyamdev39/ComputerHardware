# 14 — Performance & Upgrade Planning

## 1. Bottleneck

A bottleneck is a resource that limits overall performance for a particular workload.

There is no universal "best" upgrade.

## 2. Upgrade Analysis

Ask:

1. What workload matters?
2. What is currently limiting performance?
3. Is the platform compatible?
4. Is the PSU sufficient?
5. Are thermals sufficient?
6. What is the cost?
7. What improvement should be expected?

## 3. Common Upgrade Patterns

### More RAM
Useful when workloads regularly exhaust available memory.

### SSD Upgrade
Useful when storage capacity, latency or throughput is limiting.

### GPU Upgrade
Useful for GPU-bound games or compute workloads.

### CPU Upgrade
Useful for CPU-bound workloads if the platform supports the upgrade.
