# 01 — Computer Fundamentals

## 1. What Is a Computer?

A computer is an electronic system that accepts data, processes it according to instructions, stores information, and produces output.

The simplified model is:

```text
Input → Processing → Output
            ↕
          Storage
```

## 2. Hardware vs Software

**Hardware** is the physical equipment: CPU, RAM, motherboard, SSD, keyboard, etc.

**Software** is the set of instructions that tells hardware what to do: operating systems, applications, drivers, etc.

## 3. Data Units

- Bit: 0 or 1
- Byte: 8 bits
- KB, MB, GB, TB: larger data units

Be careful: decimal storage manufacturers and binary memory conventions can use different measurement bases.

## 4. Core Components

| Component | Primary role |
|---|---|
| CPU | Executes instructions |
| RAM | Holds actively used data/instructions |
| Storage | Persistent data |
| Motherboard | Connects major components |
| GPU | Processes graphics/parallel workloads |
| PSU | Supplies electrical power |
| Cooling | Removes heat |
