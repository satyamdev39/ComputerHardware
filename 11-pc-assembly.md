# 11 — PC Assembly

## 1. Preparation

Before assembly:

- Work on a clean surface.
- Disconnect power.
- Organize screws and components.
- Use appropriate ESD precautions.
- Read component manuals.

## 2. Typical Sequence

```text
CPU
 ↓
RAM
 ↓
M.2 SSD (if applicable)
 ↓
CPU cooler
 ↓
Motherboard into case
 ↓
PSU
 ↓
GPU
 ↓
Power/data/front-panel connections
 ↓
Inspection
 ↓
First boot
```

The exact order can vary by case and hardware.

## 3. Compatibility Checklist

Verify:

- CPU ↔ motherboard socket
- Motherboard ↔ case form factor
- RAM generation ↔ motherboard
- Cooler mounting ↔ socket
- GPU ↔ case clearance/slot
- PSU ↔ system requirements/connectors
- Storage ↔ interface/slot availability
