# 10 — BIOS, UEFI & Firmware

## 1. Firmware

Firmware is software stored in non-volatile memory that provides low-level control and initialization for hardware.

## 2. POST

Power-On Self-Test is part of the startup process used to initialize/check hardware before handing control to the boot process.

## 3. BIOS vs UEFI

UEFI is the modern firmware interface used by most contemporary PCs. "BIOS" is still commonly used informally to refer to firmware setup.

## 4. Boot Order

Firmware determines which bootable device is attempted according to configured boot settings.

## 5. Secure Boot

Secure Boot is a UEFI feature designed to help ensure that trusted boot software is loaded.
